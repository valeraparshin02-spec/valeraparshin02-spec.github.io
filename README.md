# Портфолио Валерия

Локальный одностраничный сайт-портфолио на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Перед публикацией

1. Проверить актуальность Telegram-ссылки в `src/config.js`.
2. Проверить формулировки по кейсам в `src/data/cases.js`.
3. Собрать проект командой `npm run build`.

Проект не публикуется автоматически.
